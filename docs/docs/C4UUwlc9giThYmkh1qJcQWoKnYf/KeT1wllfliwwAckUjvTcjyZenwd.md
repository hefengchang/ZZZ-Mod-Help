# 绝区零mod获取网站

踩蘑菇网：国人自己的mod网站，含有丰富的教程工具和mod，https://www.caimogu.cc/circle/437.html

创作者订阅制众筹平台：需要vpn翻墙，拥有很多优秀的mod创作者

https://www.patreon.com/explore/search?type=campaign&query=Zenless%20Zone%20Zero

香蕉网：需要vpn翻墙，https://gamebanana.com/games/19567

可在B站搜索教程，或者看下面的教程

ReplaceGoogleCDN扩展插件下载和安装方法教程

https://www.chajianxw.com/accessibility/38673.html

推荐浏览器：

自带的Eege，夸克浏览器.需要开启ad广告拦截器去除广告.

扩展插件一般是crx格式或者压缩文件的格式，如果crx格式拖进浏览器扩展显示无效可更换后缀crx为zip再拖进去，还不行就把zip文件解压缩，然后点击加载解压缩的扩展手动添进去。

只要添加了这个扩展插件，就可以直接登录香蕉网了。
