# 快捷键命令说明

## 常用命令

F10-----重载模组，用于刷新添加、修改或删除模组等操作后带来的变化

F6-----禁用/启用模组，用于禁用或启用Mod文件夹内的所有模组

F1-----显示/隐藏此帮助菜单，用于在游戏中显示或隐藏左上角的帮助信息（在XXMI中为禁用状态）

Ctrl+Alt+F10-----删除并重置d3dx_user.ini文件，用于恢复默认的一些设置，比如存储的切换类模组初始状态（举例模组原来有袖子，使用切换快捷键后没有袖子，然后使用F10保存了这个状态以便每次使用该模组都保持没有袖子，那么可以使用该快捷键来恢复成原来有袖子的状态）

## 开发者命令

Numpad0-----打开/关闭绿色狩猎文本

F8-----执行帧转储

F9-----按住时切换模组

Ctrl+F9-----性能监视器

Numpad+-----重置狩猎缓冲区（在狩猎之间做得很好，可以减少你需要循环的次数）

前2个循环向前/向后，最后一个循环（下方灰色标注）为VS/PS复制哈希和转储着色器：

Numpad/*------循环VB（顶点缓冲区）

Numpad 7 8 9-----循环IB（索引缓冲区）

数字键盘4 5 6-----循环VS（顶点着色器）

数字键盘1 2 3-----循环PS（像素着色器）
