# RabbitFX相关问题

绝区零的发光插件，地址[https://gamebanana.com/mods/531649](https://gamebanana.com/mods/531649)

该插件要保证mod文件夹里只存在一个，否则会导致很多异常现象。可在Mods文件夹搜索RabbitFX，看是否存在多个，全部删除下载最新版或者其他版本。

问题关键词：变黑、切人崩溃、发光异常、特别亮、残影、拖影、闪退
