# 游戏切到某个mod时会崩溃

1.遇到崩溃问题时最常见的方法是移除所有模组，然后逐个添加以找到导致崩溃的模组。

2.另一个崩溃的原因是 RabbitFX，作者明确指出 RabbitFX 只能存在一个，否则会导致崩溃。你需要在mod文件夹里搜索RabbitFX，删除多余的只留一个。或者删除所有旧的，下载最新版的。
