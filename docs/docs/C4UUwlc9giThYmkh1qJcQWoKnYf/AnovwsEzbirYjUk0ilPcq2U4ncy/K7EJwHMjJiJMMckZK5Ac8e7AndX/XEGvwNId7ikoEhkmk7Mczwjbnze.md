# 角色没有装mod，但贴图错误

其他的mod中存在该角色的一些hash值，并且应用到了贴图中。

你需要将所有mod移除mod文件夹再一个个添加，直到找到造成错误的那一个mod。然后查看mod的ini文件，删除那些错误hash值的节。
