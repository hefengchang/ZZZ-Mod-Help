# 如何关闭红字报错

使用游玩版会屏蔽红字，而开发版需要手动关闭。

1. 打开你所需要的加载器的目录，目录大致的样子如图：

<img src="/assets/Brwjb9t22otR3GxeCY4cS6nSnbb.png" src-width="387" src-height="548" align="center"/>

1. 以txt，也就是文档的方式，打开d3dx.ini，然后你会看到如图：

<img src="/assets/Q08Zb1Hwsog7SfxbdOzcJE2bnbb.png" src-width="932" src-height="725" align="center"/>

1. 紧接着，快捷键ctrl + f，搜索框输入Logging如图：

<img src="/assets/QD3qbPScQondzTxcAXRcnBqJnka.png" src-width="939" src-height="730" align="center"/>

1. 在[logging]下一行自行输入dev = 0 如图：

<img src="/assets/YMFPbjIgKoQvdyxz72JcDJ0Wn4f.png" src-width="687" src-height="395" align="center"/>

1. ctrl+s保存d3dx.ini，重新打开加载器可以使用了。

补充：

dev = 0 【关闭报错】

dev = 1 【开启报错】
