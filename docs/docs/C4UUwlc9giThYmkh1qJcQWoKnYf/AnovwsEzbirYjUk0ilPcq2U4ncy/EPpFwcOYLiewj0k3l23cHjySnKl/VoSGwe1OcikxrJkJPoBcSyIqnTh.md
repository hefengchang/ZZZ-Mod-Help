# 游戏异常

常见特效异常，大世界异常，角色异常。

解决办法：

1. 有不属于加载器的多余的文件或文件夹，如中文文件夹，残留的文件。要么找到它们删除，要么卸载后重新安装。
2. mod冲突，需要移除所有mod，看是否恢复正常。恢复正常则说明有些mod出现冲突或损坏，需要逐个添加来确认异常mod。
3. ShaderCache和ShaderFixes文件夹里有异常文件，需要移除里面的文件看是否恢复正常，或者卸载当前使用的加载器管理器，重新下载并安装到另一个磁盘中。
4. 卸载当前管理器或加载器，重新下载最新版的XXMI使用。
