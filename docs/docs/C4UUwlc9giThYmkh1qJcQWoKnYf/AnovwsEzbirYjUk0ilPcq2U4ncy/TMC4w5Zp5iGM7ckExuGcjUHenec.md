# 玻璃颜色异常，特效异常

玻璃等透明物体的颜色变绿，或者特效颜色异常。

1.常见于旧版本的XXMI,你需要删除ShaderFixes文件夹并重启和修复 XXMI,同时Mods文件夹里不要有ShaderFixes同名的文件夹。如果还不行，就卸载XXMI并换个盘安装。

2.某些mod使用了着色器来改变特效颜色，这将有可能导致颜色与特效异常，需要移除相关mod来恢复。

相关问题参考：https://gamebanana.com/questions/88133

                      https://gamebanana.com/questions/84769

3.游戏文件缺失，使用米哈游启动器中的一键修复功能。
