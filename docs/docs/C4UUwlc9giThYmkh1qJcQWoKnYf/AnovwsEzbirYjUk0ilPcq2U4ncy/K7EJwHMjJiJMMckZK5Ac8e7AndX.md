# 贴图与模型相关问题

1.优先使用版本修复工具进行修复。不要一个角色装多个mod，会冲突导致贴图错误。

2.多个mod存在相同的hash，导致的冲突。需要移除所有mod，再一个个添加来找到问题。

3.部分mod需要刷新地图场景来加载正常，推荐切换角色来解决。

4.下载[SlotFix插件](https://www.caimogu.cc/post/2095785.html)（只能存在一个），新版的xxmi制作的mod如果不是xxmi用户就需要下载这个。

5.mod本身存在问题，重新下载该mod。找作者修复，或者打开左上角红字报错功能查看是否有红字报错，自己修复。当然你也可以在[踩蘑菇上](https://www.caimogu.cc/user/1761398.html)私信我修复。

6.卸载所有Mod并删除除了Mods文件夹以外的所有文件，然后修复ZZMI。
