# 游戏设置问题（优先选择）

1. 将“全局光照”设置为“高”
2. 将“角色质量”设置为“高”   (会导致mod只在角色界面生效，大世界不生效)
3. 关闭“角色动态高精度”
4. 可选：关闭“体积雾”
5. 可选：开启“高光溢出”
6. 可选：抗锯齿切换“SMAA”
7. 可选：关闭“运动模糊”（会导致透明布料出现叠影）
8. 可选：关闭第三方滤镜
9. 关闭英伟达的AI插帧功能
10. 50系列的英伟达显卡有一个Smooth Vision（平滑运动）或者Mouvement fluide（流体运动）的功能,请关闭
11. 在米哈游启动器上关闭DX12选项，mod只能用DX11

Mod出问题优先将设置更改为上述配置
