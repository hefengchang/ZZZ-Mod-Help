# 高低显切换工具

下载地址：[高低显切换工具](https://zzzmod.lanzoub.com/iEBfJ329xh1g)

此工具可以自动完成切换设备高低显方法中提到的修改方法来切换高低显配置。

<img src="/assets/W6vhb5CtcoFRtYxnQaLc2hDBn5e.png" src-width="502" src-height="412" align="center"/>

点击相应的按钮进行切换后，会提示是否重启：

<img src="/assets/FdQSbWF1WopKeUxbAAWcCI5OnEg.png" src-width="598" src-height="490" align="center"/>

如果软件权限不够导致修改注册表失败，可以尝试使用管理员身份运行：

<img src="/assets/GmBLb71QfoQ6UnxOrLycezHinwc.png" src-width="598" src-height="734" align="center"/>

右键属性，兼容性选项卡，设置中勾选“以管理员身份运行此程序”即可。
