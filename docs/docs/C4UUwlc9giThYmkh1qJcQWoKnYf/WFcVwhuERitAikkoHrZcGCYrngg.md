# mod制作相关软件

<b>以下标题均为链接，点击即可直达软件官方网站。</b>

## <b>XFLTD养鸡场</b>

https://www.xfltd.org/#/register?code=YqvU0kPy

便宜好用的梯子，解决访问外网的问题。自动链接被限制，请复制链接在浏览器打开。

请注意这并非免费的梯子，因为以下软件有些需要访问外网，故做推荐。

## [python](https://www.python.org/downloads/)

Python 是一种高级、解释型、通用的编程语言，以简洁和易读性著称。一些mod相关工具会使用该编程语言来支持运行，它们通常以py为文件名后缀。

## [paint.net](https://github.com/paintdotnet/release/releases)

paint.net 是一款免费的图像和照片编辑软件,支持dds格式图片的查看编辑，用于预览打开mod的dds格式纹理贴图。

## [Blender](https://www.blender.org/download/lts/4-2/)

Blender 是一款开源的三维建模、动画、渲染、视频剪辑和后期处理软件。用于3D模型的制作。

## [Photoshop](https://www.adobe.com/hk_en/products/photoshop.html)

Adobe Photoshop（简称Photoshop，常被称为PS）是由Adobe Systems开发的一款专业图像处理软件。

可在b站搜索免费安装教程。

## [Visual Studio Code](https://visualstudio.microsoft.com/zh-hans/)

Visual Studio Code（简称 VSCode）是由微软开发的一款开源代码编辑器，它以其轻量级、功能强大和高度可定制性而受到广泛欢迎。用于py程序或者ini文件的阅读和修改。

## <b>ZMTB工具箱</b>

https://github.com/ZelbertYQ/ZMTB

一款自用的Blender工具箱，目前整合了一些方便制作基于3dmigoto的模组的插件。
